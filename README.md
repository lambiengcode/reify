# Reify

A local-first Rust knowledge engine that compiles a mature codebase — source, SQL, tests,
documents and Git history — into a compact system model, and serves AI coding agents the
smallest context they need to change a brownfield system correctly.

**Status: planning. No code yet.**

Read [`docs/PLAN.md`](docs/PLAN.md) — the full product and engineering plan, including the
falsification experiments and kill criteria the project is measured against.

Core principle: **deterministic first, semantic second, LLM last.**
